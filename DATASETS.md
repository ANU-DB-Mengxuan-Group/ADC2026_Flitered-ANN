# Datasets

This document describes every dataset used by this benchmark. The datasets fall into three groups: the **six training datasets** taken from the FANNS benchmark of Shi et al. (2024), the **eleven V1 validation datasets** constructed specifically for the routing-rule generalization experiments, and the **five V2 validation datasets** added for the large-scale cross-distribution evaluation.

Raw vectors and labels for all named datasets can be downloaded from:

- Hugging Face: <https://huggingface.co/datasets/ffa500/filterbenchmark>

The Hugging Face bundle ships the six training datasets and the major validation corpora directly. The other validation datasets are *generated locally* from scripts in this repository (see [Synthetic-Label Datasets](#synthetic-label-datasets) below); the scripts are deterministic given the seed, so the datasets can be reproduced bit-for-bit.

## Training Set (six real-world corpora)

These six datasets follow the FANNS benchmark of Shi et al. (2024) and are downloaded from the Hugging Face bundle above. Each dataset ships in two equivalent formats (`*.fvecs` and `*.bin`); see `UNG-dev/README.md` for conversion details.

| Dataset    | Vectors    | Dim  | Labels      | Source domain          |
|------------|-----------:|-----:|------------:|------------------------|
| arXiv      | 132,687    | 768  | 4,231       | Academic paper embeddings |
| YFCC       | 1,000,000  | 192  | 181,931     | Flickr image tags (YFCC100M subset) |
| LAION-1M   | 1,000,448  | 512  | 30          | LAION image–text pairs |
| TripClick  | 1,055,976  | 768  | 29          | TripClick travel-search logs |
| YTB-Audio  | 5,000,000  | 128  | 3,862       | YouTube-8M audio embeddings |
| YTB-Video  | 1,000,000  | 1024 | 3,862       | YouTube-8M video embeddings |

Each training dataset has three query sets corresponding to the three filter scenarios (Containment / Overlap / Equality) plus a Fixed-EQ synthetic-label variant. The naming convention is `<dataset>_query_<scenario>.{bin,txt}`, where `<scenario>` is `and` / `or` / `equal` / `fixed_eq`.

## V2 Validation Set (five mid-scale cross-distribution datasets)

The V2 set adds 500K–800K-vector datasets to test routing transfer to distributions noticeably larger and (for the two text corpora) substantially different from the V1 training set. The three synthetic datasets are generated by `analysis/generate_validation_v2.py`; the two real-world text datasets are downloaded and converted by `analysis/run_prepare_real_datasets.sh`.

| Dataset           | Vectors  | Dim  | Cardinality | Notes                                                  |
|-------------------|---------:|-----:|------------:|--------------------------------------------------------|
| synth\_192d       | 800,000  | 192  | 200         | Matches YFCC dimension                                 |
| synth\_512d       | 800,000  | 512  | 30          | Matches LAION dimension + cardinality                  |
| synth\_768d\_hc   | 800,000  | 768  | 1,000       | Matches arXiv/YTB dimension; high cardinality          |
| yahoo800k         | 800,000  | 768  | 14          | Yahoo Answers, sentence-transformer embedding (text)   |
| dbpedia560k       | 560,000  | 768  | 14          | DBpedia entities, sentence-transformer embedding (text)|

### Generation commands

```bash
# Synthetic V2 datasets (run individually per dataset)
cd ~/benchmarks/discrete
python analysis/generate_validation_v2.py --dataset synth_192d
python analysis/generate_validation_v2.py --dataset synth_512d
python analysis/generate_validation_v2.py --dataset synth_768d_hc

# Real-world text V2 datasets (download + embed + label conversion)
bash analysis/run_prepare_real_datasets.sh
```

## Synthetic-Label Schemes

Three label-generation schemes are used across the repo, each with a dedicated script:

1. **Fixed-EQ** (controlled-uniform Equality experiment, Section 3.3 of the thesis).
   - Four independent categorical attributes × three values each → twelve unique label values, eighty-one attribute combinations.
   - Selectivity per combination ≈ 1.23 %; uniform distribution; seed = 42.
   - Per-method generators: `ACORN/generate_acorn_synthetic_labels.py`, `NHQ/generate_synthetic_nhq_labels.py`, `CAPS/generate_caps_labels.py`, `UNG-dev/generate_ung_synthetic_labels.py`, `DiskANN/apps/utils/generate_synthetic_labels.cpp`. All four implementations follow the same seed/scheme so labels are consistent across methods.
2. **V1 Zipf labels** (label-dimension and label-cardinality groups; thesis-only, not used in the CIKM paper — see V1 validation section at the bottom).
   - `analysis/generate_synthetic_labels.py` produces Zipf-distributed labels with configurable cardinality and average labels per vector.
3. **V2 Zipf labels** (synth\_192d / synth\_512d / synth\_768d\_hc).
   - `analysis/generate_validation_v2.py` generates both the synthetic vectors and the matching Zipf labels in one pass, parameterized to hit the target (dimension, cardinality, LID) tuple listed in the V2 table above.

For each generated dataset the script also writes the three scenario query sets (`*_query_and.bin`, `*_query_or.bin`, `*_query_equal.bin`) and the corresponding label files.

## Ground-Truth Generation

Ground-truth top-10 IDs for each (dataset, scenario) pair are produced by the UNG brute-force tool. Example for the `words` toy dataset (full commands and parameter explanations live in the project README):

```bash
cd UNG-dev/build
./tools/compute_groundtruth \
    --data_type float --dist_fn L2 \
    --base_bin_file ../data/words/words_base.bin \
    --query_bin_file ../data/words/words_query_and.bin \
    --base_label_file ../data/words/label_base.txt \
    --query_label_file ../data/words/words_query_and.txt \
    --gt_file ../data/words/words_gt_and.bin \
    --scenario containment --K 10 --num_threads 16
```

Replace `containment` with `overlap` or `equality` for the other two scenarios; the equivalent Fixed-EQ variant is `equality` with the synthetic label files.

## Dataset Difficulty Metrics

The routing features used by the thesis (mean local intrinsic dimensionality, relative contrast, distribution factor, per-label LID ratio) are computed by:

- `tools/dataset_metrics.py` — corpus-level LID, RC, DF.
- `tools/per_label_lid.py` — per-label LID and normalised ratio (Section 4.5 of the thesis).
- `tools/run_dataset_metrics.sh` — driver script that iterates over all datasets.

Their outputs are written as `analysis/<dataset>_metrics.json` and `analysis/per_label_lid/<dataset>/...` and are kept in the repository as small reproducibility artifacts.

## V1 Validation Set (eleven controlled-variable datasets, thesis-only)

> **Scope note.** The V1 validation set is **not used in the CIKM paper**. It was constructed for the rule-router generalization experiments in a companion thesis (author redacted for double-blind review), where eleven small, controlled-variable corpora isolate the individual effects of label structure, label cardinality, and local intrinsic dimensionality (LID) on the rule-based router. The CIKM submission instead reports the larger-scale V2 cross-distribution evaluation described above. Generation scripts are kept in this repository for reproducibility of the thesis results; readers reproducing only the CIKM experiments can safely skip this section.

All eleven V1 datasets are constructed locally; their generation scripts are checked in.

### Label-dimension group (vary label structure, fix vector space)

Base vectors come from the `arxiv-for-fanns-medium` dataset of Shi et al. (2024) (100 K vectors, 4096 dim, LID ≈ 20.1).

| Dataset             | Label source                    | Cardinality | Avg labels/vec | Generation                          |
|---------------------|---------------------------------|------------:|---------------:|-------------------------------------|
| synth200            | Synthetic Zipf (exponent 0.8)   | 200         | 3.0            | `analysis/generate_synthetic_labels.py` |
| arxiv\_fanns\_real  | Native arXiv subcategories      | 175         | 1.71           | shipped on Hugging Face             |

### Label-cardinality group (vary cardinality, fix LID)

Same vector base as above.

| Dataset  | Cardinality | Avg labels/vec | Generation                                  |
|----------|------------:|---------------:|---------------------------------------------|

| synth100 | 100         | 1.5            | `analysis/generate_synthetic_labels.py`     |
